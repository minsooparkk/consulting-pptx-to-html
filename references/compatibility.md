# 호환 범위와 검수 기준

## 기준

입력은 일반 OOXML `.pptx`다. 원본 문구·장수·순서·슬라이드 크기를 유지하고 EMU를 96 CSS px/in으로 변환한다. 도형의 z-order를 유지하며 마스터, 레이아웃, 실제 슬라이드 순으로 배경 요소를 그린다. 16:9를 강제로 적용하지 않고 입력의 비율을 사용한다.

이 변환기는 PowerPoint의 전체 렌더링 엔진을 구현한 것이 아니다. `PASS_STRUCTURE`는 지원 텍스트와 장수의 HTML 직렬화 검사를 통과했다는 뜻이다. 원본과의 시각적 동등성은 별도 판정이다.

## 지원 및 제한

| 요소 | 처리 |
|---|---|
| 문단·텍스트 구간 | 글꼴 이름·크기·굵기·색·기울임·밑줄·취소선·명시적 줄바꿈·문단 간격을 HTML로 표시 |
| 상속 서식 | 사용된 플레이스홀더의 layout/master 좌표, 목록 단계 기본 글꼴·문단 속성을 우선순위에 따라 적용 |
| 글꼴 | 명시적 글꼴과 기본 테마 글꼴 처리. 언어별 보조 글꼴·폰트 대체·커닝·렌더러의 줄바꿈은 완전 동등하지 않을 수 있음 |
| 마스터·레이아웃 | 일반 도형·텍스트·장식을 반복. 미사용 플레이스홀더 예시 문구는 출력하지 않음. 자동 날짜·Footer의 모든 특수 조합을 보장하지 않음 |
| 색상·배경 | RGB, 기본 scheme/system 색, alpha, 일부 명도·채도 변환, 단색과 선형 그라데이션 |
| 사각형·직선·타원 | SVG로 표현. 선색·굵기와 기본 화살촉 지원 |
| 기타 기본 프리셋 | 삼각형·마름모·오각형·육각형·평행사변형·사다리꼴·chevron·좌우 화살표. 일부 프리셋 조정값은 기본 윤곽으로 근사하고 경고 |
| 자유형 경로 | 숫자 좌표의 move/line/cubic/quad/close. 수식·arc 경로는 미지원 오류 |
| 그림자 | outer shadow를 CSS 필터로 근사. 그림자 경고와 개수를 기록. 광선·반사·3D 등은 미지원 |
| 그룹 | 자식 좌표계의 이동·크기를 재귀 처리. 확대·축소 그룹의 글꼴·여백은 경고, 그룹 반전은 오류. 회전 텍스트는 수동 검수 |
| 표 | 명시적 셀 배경·테두리·여백·정렬·행높이·열너비·기본 병합을 HTML 표로 표시. CSS 테두리 픽셀 반올림이 있을 수 있음 |
| 테이블 스타일 | tableStyleId 기반 조건부 서식 전체를 해석하지 않음. 기본 스타일에만 의존한 표는 직접 셀 서식을 지정하거나 요소 대체 필요 |
| 그림 | 내장 PNG·JPEG·GIF·WebP·BMP 및 수동 검사에 통과한 SVG를 data URI로 포함. 직사각형 크롭과 반전 지원 |
| 특수 그림 | EMF·WMF·TIFF, 비직사각형 마스크, 이미지 효과·타일·테두리는 요소 대체 필요 |
| SVG 보안 | script, foreignObject, style, 일부 애니메이션, 외부 참조·이벤트 속성은 거절. 일반적인 정적 SVG만 허용 |
| 링크 | HTTP(S)·mailto·tel 텍스트 링크. 새 탭과 noopener. 내부 슬라이드/매크로/프로그램 실행 링크는 경고 |
| 필드 | 페이지 번호는 현재 순서로 표시. 나머지 필드는 저장된 표시값과 경고 |
| 노트 | 기본 제외. 명시 옵션으로 본문 노트를 포함. 포함된 노트는 수신자에게도 공개됨 |
| 숨긴 슬라이드 | 장수 보존을 위해 포함하고 경고. 배포 전 사용자가 민감한 내용을 제거해야 함 |
| 차트·SmartArt·OLE·미지원 그래픽 | 오류, 검토 표시, object_id. 승인된 요소 단위 PNG/SVG 대체 지원 |
| 애니메이션·전환·댓글·첨부 파일 | 재생/첨부하지 않고 존재하면 보고. 슬라이드 이미지 전체 대체는 자동으로 하지 않음 |

## 일부 기능은 근사다

- PowerPoint와 CSS의 글꼴 메트릭·행간·줄바꿈 규칙은 동일하지 않다. 글꼴 이름과 크기를 같게 지정해도 줄 끝이 달라질 수 있다.
- 그림자·선형 그라데이션의 각도·화살촉 크기·복합 선·테두리 반올림은 원본과 대조해야 한다.
- 브라우저 감사는 2.5 CSS px 오차를 허용한다. 정상으로 나온 작은 오차까지 같다는 의미는 아니다.
- 지원 범위 안의 문서라도 아주 복잡한 상속 조합, 회전·스케일 그룹, 표 조건부 서식은 비교 검수가 필요하다.
- 요소 대체 파일은 사람이 원본과 일치하는지 확인해야 한다. 대체 요소 내부 글자는 편집·검색 가능한 HTML 텍스트가 아니다.

## 완료 판정 순서

1. 원본을 변경하지 않았는지 확인한다.
2. PPTX와 HTML의 장수·순서를 맞춘다.
3. 변환 보고서의 모든 오류를 해결하고 경고를 검토한다. `--allow-unsupported`로 완료 판정을 우회하지 않는다.
4. 지원 텍스트의 문자열·수치·수동 줄바꿈을 대조한다. 직렬화 해시는 미지원 그래픽 내부의 내용 완전성을 보증하지 않는다.
5. 모든 HTML 슬라이드의 넘침과 캔버스 밖 요소를 측정한다.
6. 제목·Header·Footer·표·연결선·크롭·그림자를 PowerPoint 원본과 같은 크기로 비교한다.
7. 이동, 해시 초기화, 실제 사용자 입력에 의한 전체 화면, 편집·저장, 브라우저 인쇄를 확인한다.
8. 실제로 못 한 검사는 `미실시` 또는 `환경 제한`으로 남긴다. HTML 검사만 하고 PowerPoint 비교를 완료했다고 말하지 않는다.

## 파일 공개 범위

공개 여부와 관계없이 스킬 저장소에는 일반화한 예제만 넣는다. 고객·개인 자료, 실제 강의 원문, 개인 이름이나 출처 노트, 재배포 권한을 확인하지 않은 폰트는 자동 업로드하지 않는다. 원본을 복사한 HTML도 동일한 콘텐츠를 담은 문서다.
