# 호환 범위와 검수 기준

## 기준

입력은 일반 OOXML `.pptx`다. 원본 문구·장수·순서·슬라이드 크기를 유지하고 EMU를 96 CSS px/in으로 변환한다. 도형의 z-order를 유지하며 마스터, 레이아웃, 실제 슬라이드 순으로 배경 요소를 그린다. 16:9를 강제로 적용하지 않고 입력의 비율을 사용한다.

이 변환기는 PowerPoint의 전체 렌더링 엔진을 구현한 것이 아니다. `PASS_STRUCTURE`는 지원 텍스트와 장수의 HTML 직렬화 검사를 통과했다는 뜻이다. 원본과의 시각적 동등성은 별도 판정이다.

## 지원 및 제한

| 상속 서식 | 사용된 플레이스홀더의 layout/master 좌표, 목록 단계 기본 글꼴·문단 속성을 우선순위에 따라 적용 |

## 백분율 행간 보정

PowerPoint의 백분율 행간은 글자 크기만의 배수가 아니라 글꼴의 자연 행높이를 기준으로 할 수 있다. CSS에 원본 배수를 그대로 넣으면 줄 사이가 좁아질 수 있다. Pretendard에는 실측된 자연 행높이 계수 1.2를 기본 적용한다.

- 백분율 행간: 원본 배수 × 글꼴 계수. Pretendard 1.1 → CSS 1.32, 1.05 → CSS 1.26.
- 점 단위 행간: 원본 값을 CSS 단위로 변환하며 글꼴 계수를 곱하지 않는다.
- 다른 글꼴: Pretendard 계수를 전역으로 적용하지 않는다. 글꼴 이름·크기·상자 좌표·원문은 보정 대상이 아니다.

원본 PowerPoint에서 인접한 두 줄의 기준 위치 간격을 측정해 `실제 줄 간격 / (글자 크기 × 원본 행간 배수)`로 계수를 구할 수 있다. COM을 사용할 수 있으면 줄별 텍스트 범위의 위치와 문단 행간을 확인한다. 같은 글꼴의 여러 크기와 본문·표를 함께 대조해 결정한다. 혼합 글꼴·다른 크기의 run·회전 텍스트는 이 단일 계수만으로 동일한 줄바꿈과 행높이를 보장하지 않는다.

필요한 글꼴만 `--line-height-factor "FAMILY=FACTOR"`로 지정하며 반복 사용할 수 있다. Pretendard의 기본 계수도 이 옵션으로 재정의할 수 있다. 감사 보고서의 `line_height_calibration`에서 `default_factors`, `overrides`, `applications`의 글꼴·계수·원본 배수·CSS 배수·문단 수를 확인한다. 보정이 적용되었다는 사실과 실제 시각 대조 완료를 구분한다.

## 자동 등장 범위

- 기본 HTML에서는 각 슬라이드 진입 때 내용을 자동 표시한다. 요소 재생 420ms와 최대 지연 500ms로 약 0.92초 안에 완료한다. 최종 배치와 장수는 원본 기준이다.
- 방향키·Space·이전/다음 한 번은 한 슬라이드 이동이다. 항목 클릭 강조·수동 단계 공개·단계 버튼·슬라이드 자동 넘김은 기본 동작이 아니다.
- `--motion none`과 모션 감소 설정에서는 내용을 즉시 표시한다. 편집·저장·인쇄·경계 검사에서는 내용이 숨은 채 남지 않도록 처리한다.
- 자동 등장 설정은 보고서의 `motion`에 기록한다. `browser_verified: false`인 생성 직후 메타데이터는 실제 브라우저 동작을 보증하지 않는다. 원본 PPTX 애니메이션은 계속 미지원으로 보고하며, 이 HTML 효과로 재현했다고 판단하지 않는다.

## 일부 기능은 근사다

- PowerPoint와 CSS의 글꼴 메트릭·행간·줄바꿈 규칙은 동일하지 않다. 글꼴 이름과 크기를 같게 지정해도 줄 끝이 달라질 수 있다.
- 그림자·선형 그라데이션의 각도·화살촉 크기·복합 선·테두리 반올림은 원본과 대조해야 한다.
- 브라우저 감사는 2.5 CSS px 오차를 허용한다. 정상으로 나온 작은 오차까지 같다는 의미는 아니다.
- 지원 범위 안의 문서라도 아주 복잡한 상속 조합, 회전·스케일 그룹, 표 조건부 서식은 비교 검수가 필요하다.
- 요소 대체 파일은 사람이 원본과 일치하는지 확인해야 한다. 대체 요소 내부 글자는 편집·검색 가능한 HTML 텍스트가 아니다.

## 완료 판정 순서

1. 원본을 변경하지 않았는지 확인한다.
2. PPTX와 HTML의 장수·순서를 맞춘다.
3. 변환 보고서의 모든 오류를 해결하고 경고를 검토한다. `--allow-unsupported`로 완료 판정을 우회하지 않는다.
4. 지원 텍스트의 문자열·수치·수동 줄바꿈을 대조한다. 직렬화 해시는 미지원 그래픽 내부의 내용 완전성을 보증하지 않는다.
5. 자동 등장 효과가 측정을 방해하지 않는 상태에서 모든 HTML 슬라이드의 넘침과 캔버스 밖 요소를 측정한다.
6. 자동 등장이 끝난 제목·Header·Footer·표·연결선·크롭·그림자를 PowerPoint 원본과 같은 크기로 비교한다.
7. 자동 등장, 한 번 조작당 한 슬라이드 이동, 해시 초기화, 실제 사용자 입력에 의한 전체 화면, 편집·저장, 브라우저 인쇄를 확인한다.
8. 구조·단위/DOM 검사, 실제 HTML 동작, PowerPoint 시각 대조를 구분해 기록한다. 실제로 못 한 검사는 `미실시` 또는 `환경 제한`으로 남긴다. 접근 정책 우회를 요구하지 않으며 HTML 검사만 하고 PowerPoint 비교를 완료했다고 말하지 않는다.

## 파일 공개 범위

공개 여부와 관계없이 스킬 저장소에는 일반화한 예제만 넣는다. 고객·개인 자료, 실제 강의 원문, 개인 이름이나 출처 노트, 재배포 권한을 확인하지 않은 폰트는 자동 업로드하지 않는다. 원본을 복사한 HTML도 동일한 콘텐츠를 담은 문서다.
